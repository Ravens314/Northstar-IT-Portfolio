# Project 05 — Enterprise Active Directory & IAM Administration

## Project Overview

This hands-on lab simulates an enterprise Identity and Access Management (IAM) environment for Northstar Solutions, a fictional organization.

## Lab Environment

- Windows Server 2025 Standard Evaluation
- Oracle VirtualBox
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers (ADUC)
- Domain Name System (DNS)
- PowerShell
- GitHub Issues

## Infrastructure

| Component | Configuration |

## Project Objectives

- Active Directory Administration
- Identity Lifecycle Management
- User Provisioning and Deprovisioning
- Role-Based Access Control (RBAC)
- Security Group Administration
- Password Resets and Account Unlocks
- Least Privilege Access
- Group Policy Management (GPO)
- PowerShell Automation
- Access Reviews and Auditing
- IT Service Management (ITSM)
