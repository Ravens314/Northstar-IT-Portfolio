# HD-001 — Windows 11 Login Troubleshooting

## Project Overview

This lab simulates an employee reporting that they cannot sign in to a Windows 11 workstation.

## Objective

Demonstrate entry-level Help Desk troubleshooting skills by investigating Windows account information, sign-in methods, and network connectivity.

## Tools Used

- Windows 11
- Command Prompt
- Windows Settings
- GitHub Issues

## Troubleshooting Activities

1. Created Help Desk ticket INC-001.
2. Identified the signed-in Windows account using `whoami`.
3. Reviewed Windows Hello sign-in options.
4. Examined network configuration using `ipconfig`.
5. Tested connectivity using `ping`.
6. Reviewed local accounts using `net user`.
7. Documented findings and supporting screenshots.

## Lab Environment

Testing was performed on a working Windows 11 computer.

The employee sign-in problem is a fictional support scenario.

The commands demonstrate investigation techniques, not a confirmed repair of an actual login failure.
