# Northstar Solutions — Troubleshooting Report

## Ticket Information

- Ticket ID: INC-002
- Issue: Computer Running Slowly
- Technician: Ravens314
- Operating System: Windows 11
- Priority: Medium
- Status: Investigation Completed
- Lab Type: Educational Simulation

## 1. Problem Description

A fictional employee reported slow computer performance,
including delayed application launches and occasional freezing.

The investigation was performed on a separate Windows 11
computer that was functioning normally.

## 2. Troubleshooting Objectives

The objective was to investigate possible causes of slow
computer performance using built-in Windows tools.

Areas investigated:

1. CPU utilization
2. Memory utilization
3. Running applications
4. Startup applications
5. Storage capacity
6. Processor performance

## 3. Tools Used

- Windows 11 Task Manager
- Windows Settings
- Windows Snipping Tool
- GitHub Issues

## 4. Investigation Results

### CPU and Memory Overview

Initial Task Manager observations:

- CPU utilization: 9%
- Memory utilization: 70%
- Disk activity: 0%

These measurements did not indicate sustained CPU or disk
saturation during the observation.

### Memory Investigation

Applications were sorted by memory consumption.

Top applications:

| Application | Memory Usage |
|---|---|
| Google Chrome | 825.0 MB |
| ChatGPT Classic | 729.7 MB |
| Start | 190.2 MB |

Overall memory utilization was approximately 69%.

No application was confirmed to be causing a performance issue.

### Startup Application Investigation

Reviewed startup applications using Windows Task Manager.

Eleven visible applications were configured as Enabled.

Startup impact was listed as Not measured.

No startup applications were disabled.

### Storage Investigation

Reviewed storage information using Windows Settings.

| Measurement | Result |
|---|---|
| Total Storage | 934 GB |
| Used Storage | 486 GB |
| Available Storage | 448 GB |
| Installed Applications | 270 GB |
| Temporary Files | 34.3 GB |

Approximately 48% of storage remained available.

Low storage capacity was not identified as a likely cause
of performance issues on the test computer.

### CPU Performance Investigation

Reviewed the CPU Performance tab in Task Manager.

Results:

- CPU utilization: 12%
- CPU speed: 2.43 GHz
- Processes: 324
- Threads: 5,906

CPU utilization was relatively low during this observation.

## 5. Findings

1. CPU usage was not consistently high during the investigation.
2. Memory usage was approximately 69–70%.
3. Multiple startup applications were enabled.
4. The computer had substantial available storage.
5. No major performance bottleneck was confirmed.

## 6. Recommended Next Steps

If a real employee continued experiencing slow performance,
the technician should:

1. Ask when the issue occurs.
2. Identify which applications are affected.
3. Check CPU, memory, and disk usage during the slowdown.
4. Review startup applications with the employee.
5. Check for Windows and application updates.
6. Escalate persistent issues when necessary.

## 7. Resolution and Outcome

A performance investigation was completed successfully.

No configuration changes were made.

The test computer was functioning normally.

The fictional employee's reported issue was not reproduced
or resolved.
