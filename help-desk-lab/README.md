# Northstar Solutions — Help Desk Lab

## 1. Project Overview

This project simulates the responsibilities of an entry-level IT Help Desk Technician supporting employees at a fictional company.

The objective is to practice troubleshooting, ticket documentation, customer service, and technical support procedures.

## 2. Business Scenario

Northstar Solutions is a fictional company with 25 employees.

Employees occasionally experience technical problems involving computers, accounts, printers, and network connectivity.

As the Help Desk Technician, I am responsible for documenting problems, investigating issues, identifying solutions, and escalating problems when necessary.

## 3. Skills Demonstrated

- Windows 11 troubleshooting
- IT ticket documentation
- Password reset procedures
- Basic networking troubleshooting
- Hardware and software troubleshooting
- Customer service
- Incident prioritization
- Technical documentation
- Issue escalation

## 5. Help Desk Ticket Scenarios

| Ticket ID | Problem | Priority |
|---|---|---|
| INC-001 | Employee cannot sign in | High |
| INC-002 | Computer running slowly | Medium |
| INC-003 | No internet connection | High |
| INC-004 | Printer not responding | Medium |
| INC-005 | Employee needs software access | Medium |

## 6. Troubleshooting Process

For each ticket, I will:

1. Identify the reported problem.
2. Gather information from the employee.
3. Investigate the issue.
4. Perform appropriate troubleshooting.
5. Document findings.
6. Resolve or escalate the issue.
7. Record the final outcome.

## 7. Project Results

Results and troubleshooting evidence will be documented as each exercise is completed.

## 8. Disclaimer

Northstar Solutions is a fictional company created for educational purposes. All employees, incidents, and scenarios are fictional.
