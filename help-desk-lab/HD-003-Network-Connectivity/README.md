# HD-003 — Windows 11 Network Connectivity Troubleshooting

## Project Overview

**Company:** Northstar Solutions (Simulated)  
**Ticket:** INC-003  
**Issue:** Employee Unable to Connect to the Internet  
**Operating System:** Windows 11  
**Project Type:** Help Desk Troubleshooting Simulation

## Objective

Investigate a simulated employee internet connectivity issue using built-in Windows 11 diagnostic tools.

## Tools Used

- Windows PowerShell
- Windows Network Settings
- GitHub Issues
- `ipconfig /all`
- `ping`
- `nslookup`

## Troubleshooting Performed

1. Created and documented a simulated Help Desk incident.
2. Examined IP configuration and identified the default gateway.
3. Tested local network connectivity.
4. Tested external IP connectivity.
5. Verified DNS resolution.
6. Inspected wireless network adapter status.

## Key Findings

- Default gateway connectivity was successful.
- External IP connectivity was successful with 0% packet loss.
- Elevated external network latency was observed, averaging 284 ms.
- DNS successfully resolved the tested domain.
- The wireless network adapter was enabled and connected.

## Final Outcome

The investigation demonstrated foundational Windows networking and Help Desk troubleshooting skills.

No actual employee internet outage was reproduced or resolved.

Additional testing would be required to determine the cause of the elevated latency.

- DNS troubleshooting
